##Escriba un programa que muestre todos los numeros naturales en un rango
##Nota, un numero primo es aquel numero que no puede ser dividido más que por 1 y por si mismo.
##ejemplos:
## 6 no es un numero primo porque puede ser dividido por 1, por 2, por 3 y por 6
## 37 es un numero primo ya que sólo puede ser dividido por 1 y por si mismo (que es lo mismo decir que no hay otros numeros que multiplicados entre sí den 37)

##Por ejemplo, dados:
# rango
start = 25
end = 50
##Salida esperada:

Los numeros primos entre 25 y 50 son:
29
31
37
41
43
47

##Solucion
start = 25
end = 50
print("Los numeros primos entre", start, "y", end, "son:")

for num in range(start, end + 1):
    # todos los numeros primos son mayores que 1
    if num > 1:
        for i in range(2, num):
            # busco los factores
            if (num % i) == 0:
                # si no tiene, no es primo y rompo el loop
                break
        else:
            print(num)

##Escriba un programa que imprima el siguiente patrón en pantalla usando un loop

* 
* * 
* * * 
* * * * 
* * * * * 
* * * * 
* * * 
* * 
*

##Solucion
rows = 5
for i in range(0, rows):
    for j in range(0, i + 1):
        print("*", end=' ')
    print("\r")

for i in range(rows, 0, -1):
    for j in range(0, i - 1):
        print("*", end=' ')
    print("\r")

##Escriba un programa que calcule el valor de "a" a la potencia "b
##Por ejemplo:
(power(3,4)) 
El resultado es: 81

##Solucion
def power(a,b):
    if b==0:
        return 1
    elif a==0:
        return 0
    elif b==1:
        return a
    else:
        return a*power(a,b-1)

print("El resultado es: "power(3,4))

## Dado un diccionario en Python, escriba un programa en Python para encontrar la suma de todos los elementos en el diccionario.
##Ejemplos: 

Input : {‘a’: 100, ‘b’:200, ‘c’:300}
Output : 600

Input : {‘x’: 25, ‘y’:18, ‘z’:45}
Output : 88

##Solucion

def returnSum(myDict):

    list = []
    for i in myDict:
        list.append(myDict[i])
    final = sum(list)

    return final



dict = {'a': 100, 'b': 200, 'c': 300}
